## What this site documents

This is the creator reference for the **D25** content format, verified against
build `7050b38` (2026-10-28). The public game and the current sample pack still
use the earlier format; pages that depend on unreleased game UI say so at the
top. See the [format changelog](/reference/format-changelog) for the difference.
