# The sample pack

The public sample repository is
[`Bandit-Fox/Kurblanc-Samples`](https://github.com/Bandit-Fox/Kurblanc-Samples).

It is the reference pack creators will eventually download, but its current
release (`v0.2.0`) is **pre-D25**. It uses a `LP/blocks.json` catalogue, texture
keys through `terrain_texture.json`, two-file doors and two-file wall sheets. It
will not load as-is in a D25 build without conversion.

Use [Legacy catalogues](/reference/legacy-catalogues) to convert it, or start from
the wiki's fixture pack if you want a D25-shaped file today. A D25 sample release
will replace this page's warning; until then, this page stays gated.

## What the sample pack is good for

- Seeing a real set of block, item and entity definitions.
- Copying art proportions and archetype choices.
- Comparing your converted pack against a complete content set.

## Limits

- The release is pre-D25, so convert it before loading it in a D25 build.
- Start new packs from the fixture pack instead of copying its catalogue files.
- Installing it needs a D25 build with the pack manager.
